# Sahil Kumar Ekka — Portfolio Website

A static portfolio website for Sahil Kumar Ekka, illustrator and character designer.

## Project structure

```text
.
├── index.html                 # Home page
├── pages/                     # Secondary pages
│   ├── about.html
│   ├── portfolio.html
│   ├── skills.html
│   ├── contact.html
│   ├── resume.html
│   └── projects/              # Skills, experience, and education pages
├── assets/
│   ├── images/
│   │   ├── profile/sahil.jpg  # Profile photo
│   │   └── placeholders/      # Placeholder logo and project artwork
│   └── resume/
│       └── Sahil-Kumar-Ekka-Resume.pdf
├── css/                       # Stylesheets
└── js/                        # JavaScript
```

## Run locally

Open `index.html` in a browser. No build step is required for the static site.

## Notes

- Keep the relative paths intact when moving files.
- The résumé PDF in `assets/resume/` is the source for the portfolio's biographical details.
